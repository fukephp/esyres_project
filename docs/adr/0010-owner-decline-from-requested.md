# Owner may decline a request without counter-proposing

Overview diagrams only showed `declined` after `time_proposed`. Epic 3 still lets the owner refuse a `requested` booking with an optional reason, so the guest is not forced through a counter-proposal. `requested → declined` is a first-class path next to accept and counter-propose. Customer reject of a counter-proposal stays Epic 4. Expire still maps to the same `declined` status with reason `expired` (no fifth status).
