# Salon media on Informacije; guest display later

Owner salon edit Informacije now holds optional **salon description**, **main image**, and **gallery** (extras, not the main). Images use Laravel public disk and GraphQL multipart already in the stack — no Spatie, no HEIC/GIF/SVG pipeline, no thumbs/WebP/CDN. Guest `/salon/:id` UI and public `salon` GraphQL stay photoless this slice; discovery stays not photo cards (ADR 0030). Files on the public disk are not advertised on the public schema. This supersedes the photos-off clause in `docs/adr/0032-owner-salon-catalog.md` for these three Informacije fields only. Coordinates and reschedule cap stay off salon edit. Create-salon and add-salon do not collect media. Rejected: a fifth chip, Booksy/Fresha discovery cards, guest display in the same story, and collapsing main into the gallery list.
