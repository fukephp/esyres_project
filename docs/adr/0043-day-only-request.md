# Day-only request

A guest may send Pošalji zahtjev for an open day with no quarter. The row stays `requested`, stores the day, and holds no clock, so the owner can offer one free quarter on that same day with Predloži. The guest still approves or rejects that offer. A closed day cannot be sent. A tapped quarter still sends that time. The assistant and phone bookings still require a time.

Rejected: keeping the quarter required, offering several times at once, and letting Predloži jump to another day (decline is how the owner refuses the day). STORY-92.
