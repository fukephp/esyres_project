# Assign worker confirms

A no-preference request that already has a preferred time is confirmed when the owner taps a worker who is free for that whole range. The guest is not asked, and the row does not become `time_proposed`. Accept preferred time stays the one tap for a worker the guest already named. If nobody is free, the owner still counter-proposes or declines. Hours are not re-checked, matching accept.

Rejected: turning the same clock into a counter-proposal the guest must approve, and leaving Predloži as the only way to name a worker. STORY-91.
