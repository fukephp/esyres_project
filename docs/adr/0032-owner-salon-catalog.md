# Owner salon catalog and salon edit

Owners get a **salon catalog** (`/owner/salons`) of shops they own. Each shop is a hairline box: name (not a link), **open now** from working hours (not listed, not a toggle), and **Uredi** to salon edit. **Add salon** is a plus under the `Saloni` title → `/owner/salons/create` and requires they already own a salon (zero shops: same not-owner treatment as `/owner`; first shop stays `/create-salon`). Success lands on **salon edit** for the new shop (`/owner/salons/:id`, no `/edit` suffix). OwnerNav **Saloni** is on every owner route. Salon switcher stays `?salon=` on queue, chats, and stats only. The box is not a switcher and does not show queue or stats.

**Salon edit** is name + address (required, cannot blank), optional salon description, optional main image, and optional gallery of extra images on Informacije (guest profile and public GraphQL stay photoless; see `docs/adr/0037-salon-media-on-informacije.md`), the full weekly hours template already in STORY-01 (days, times, optional break, cancel window), and create/edit services and workers by name (STORY-02/03 fields). Chrome is four exclusive in-page chips (Informacije / Radno vrijeme / Usluge / Radnici) on the same `/owner/salons/:id` URL — one full-width boxed panel at a time; no nested `/edit` or `?tab=`. No worker↔service assignment matrix. No delete/deactivate of salon, service, or worker. DND stays on chats. Coordinates and reschedule cap stay off this page. **Current job** stays on Zahtjevi occupying rows (service names + worker), not on the catalog. Worker login stays Phase 2.

Rejected: a live in-chair wall on the catalog; a table-list with name-as-link and footer add; days-only hours UI; assignment matrix in this slice; changing `/create-salon`; `/owner/salons/:id/edit`; delete/deactivate; coords/reschedule cap on salon edit. Photos-off on salon edit is superseded by `docs/adr/0037-salon-media-on-informacije.md` for Informacije description / main image / gallery only.
