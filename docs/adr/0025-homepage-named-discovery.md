# `/` is the homepage; discovery is a named route

Typed `/` was a one-shot company pitch: persist “seen” in the browser, then discovery home on the same URL. That made the root a trapdoor (spoken domain, print, dual-role second tab) and blocked a real header. `/` is now the **homepage** (homepage-only header, existing hero, simple footer). Discovery home moves to a named route. Kill `esyres.companyPitchSeen` / HomeGate. Header login and register are dedicated `/login` and `/register` routes; the signed-in chip is email. `/salon/:id` and `GET /qr/{id}` never show homepage chrome. No sibling marketing site, no `/welcome`, no long-scroll marketing page. This supersedes ADR 0024’s same-URL overlay; the no-second-Vite-app rule stands. Owners stay invite-only until that lock is explicitly reversed.
