# Guest picker uses quarter starts and shows Zauzet

Pošalji zahtjev no longer takes a typed time. The guest picks a quarter start inside that day’s open range. A start whose service range overlaps an occupying booking (`confirmed` or `time_proposed`) is Zauzet: visible, not tappable, and rejected if sent on the picker path. A named worker uses that worker’s book; no preference is Zauzet only when every worker is blocked. A pending request does not occupy, so it does not make a quarter Zauzet, and sending still creates `requested`. Chat stays 1–3 coarse suggestions plus a typed other time, and does not show this list. Owner counter-propose, Telefon Drugi dan, and My Bookings keep a typed clock.

The other live option was preference chips with no taken state, which hid the clash until the owner answered. The guest already meets this pattern on the owner’s Telefon day. Showing Zauzet answers “can I come then?” without holding the chair or giving the guest the book of names.
