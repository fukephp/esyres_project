# STORY-37 — QR conversion stats

| Field | Value |
|-------|--------|
| ID | STORY-37 |
| Epic | 9 — Basic Stats & Owner Insights |
| Loop | — |
| Depends on | STORY-34 |

## User story

As an owner, I want to see how many people scanned my QR code and how many converted into verified visits, so that I know if the sticker is working.

## Acceptance criteria

- Owner can see QR scan count for the selected salon.
- Owner can see how many of those scans became verified visits (reconcile at verification).
- Stats use captured scan/visit data from STORY-34; no badge display.

## Out of scope

- Trust badge UI
- Marketing attribution beyond this QR
- Customer-facing scan stats
