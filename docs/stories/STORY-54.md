# STORY-54 — Services on salon edit

| Field | Value |
|-------|--------|
| ID | STORY-54 |
| Epic | 7 — Salon & Service Management (Owner Onboarding) |
| Loop | `STORY-54` |
| Depends on | STORY-02, STORY-51 |

## User story

As an owner, I want to add and edit services by name on salon edit, so that customers see accurate options without a second settings app.

## Acceptance criteria

- Salon edit lists that salon’s services and can create/update with STORY-02 fields: name, category (hair / make-up / massage), price in feninga, optional duration on create (omit → 30 minutes). Same rejection rules as STORY-02.
- Rename/update only. No delete or deactivate. No worker↔service assignment matrix.

## Out of scope

- Delete / hide service
- Worker assignment matrix (later)
- Service photos, descriptions, packages
- Workers UI (STORY-55)
