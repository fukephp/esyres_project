# Answer keys

Filled per-story answer keys live here as `STORY-xx.md` (or a clear story id from `docs/mvp/07-Stories.md`).

Copy from `../ANSWER_KEY_TEMPLATE.md`. Set **Status** to `approved` only after a human has signed off. The `story-loop` skill will not implement (Local default) or emit a Cloud paste against a draft key. Follow **Implementer instructions** in the key.

See `../PLAYBOOK.md` for the full loop contract.
