# Answer keys

Filled per-story answer keys live here as `STORY-xx.md` (or a clear story id from the stories source named in CONTEXT).

Copy from `../ANSWER_KEY_TEMPLATE.md`. Every product check must name a verifier (human-only cap 1–2). Set **Status** to `approved` only after a human has signed off. The `story-loop` skill will not implement (Local default) or emit a Cloud paste against a draft key. Follow **Implementer instructions** in the key.

See `../PLAYBOOK.md` for the full loop contract.
