# Story maps

Wayfinder-lite maps for foggy MVP stories live here as `STORY-xx.md`.

Copy from `../MAP_TEMPLATE.md`. Use a map only when fog is **non-trivial** (see `../PLAYBOOK.md`). When **Not yet specified** and **Open decisions** are empty, the `story-loop` skill compiles a **draft** `.cursor/loops/answer-keys/STORY-xx.md` in the same turn and sets map Status to `compiled`. You approve the key, not the compile. If a likely product check has no verifier, it stays in this map.

Sharp stories may skip this folder and go straight to an answer key.
