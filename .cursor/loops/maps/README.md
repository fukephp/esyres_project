# Story maps

Wayfinder-lite maps for foggy MVP stories live here as `STORY-xx.md`.

Copy from `../MAP_TEMPLATE.md`. Use a map only when fog is **non-trivial** (see `../PLAYBOOK.md`). When **Not yet specified** and **Open decisions** are empty and a human OKs compile, the `story-loop` skill compiles `.cursor/loops/answer-keys/STORY-xx.md` and sets map Status to `compiled`.

Sharp stories may skip this folder and go straight to an answer key.
